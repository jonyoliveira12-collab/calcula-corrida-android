## Tamanho e posição da etiqueta

No aplicativo, abra **Configurações → Etiqueta flutuante → Tamanho e posição das etiquetas**. O controle ajusta o tamanho de 60% a 160%. Durante a leitura, arraste a etiqueta para qualquer ponto da tela; a posição fica salva por aplicativo e orientação.
